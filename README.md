# موقع جامعة العين العراقية | Al-Ayen Iraqi University Website

موقع إلكتروني متعدد اللغات (عربي/إنجليزي) لجامعة العين العراقية، مبني باستخدام Next.js 16 و TypeScript.

## 🚀 المميزات

- ✅ دعم كامل للغتين العربية والإنجليزية مع RTL
- ✅ تصميم متجاوب يعمل على جميع الأجهزة
- ✅ 11 كلية مع 28 قسماً أكاديمياً
- ✅ نظام أخبار متكامل مع البحث والفلترة
- ✅ صفحات ديناميكية للكليات والأخبار
- ✅ روابط للأنظمة الإلكترونية والمواقع البحثية
- ✅ تصميم عصري وجذاب مع Tailwind CSS

## 📋 المتطلبات

- Node.js 18.17 أو أحدث
- npm أو yarn

## 🛠️ التثبيت

```bash
# تثبيت المكتبات
npm install

# تشغيل المشروع في وضع التطوير
npm run dev

# بناء المشروع للإنتاج
npm run build

# تشغيل المشروع في وضع الإنتاج
npm start
```

## 🌐 الصفحات المتاحة

- `/ar` - الصفحة الرئيسية (عربي)
- `/en` - الصفحة الرئيسية (إنجليزي)
- `/ar/about` - عن الجامعة
- `/ar/colleges` - قائمة الكليات
- `/ar/colleges/[id]` - تفاصيل الكلية
- `/ar/news` - قائمة الأخبار
- `/ar/news/[slug]` - تفاصيل الخبر
- `/ar/contact` - اتصل بنا

## 🎨 التخصيص

### تحديث البيانات

يمكنك تحديث بيانات الموقع من خلال تعديل ملفات JSON في مجلد `data/`:

- `colleges.json` - إضافة أو تعديل الكليات والأقسام
- `news.json` - إضافة أخبار جديدة
- `links.json` - تحديث الروابط الخارجية
- `stats.json` - تحديث الإحصائيات
- `about.json` - تحديث معلومات الجامعة

### تحديث الترجمات

عدّل ملفات الترجمة في مجلد `messages/`:

- `ar.json` - النصوص العربية
- `en.json` - النصوص الإنجليزية

### تخصيص الألوان

عدّل ألوان الجامعة في `tailwind.config.ts`:

```typescript
colors: {
  university: {
    primary: '#1e40af',    // اللون الأساسي
    secondary: '#059669',  // اللون الثانوي
    accent: '#dc2626',     // لون التمييز
  },
}
```
